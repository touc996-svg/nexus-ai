# NEXUS AI Public Demo

## Hosting
The public demo is configured for a Render free web service.

## Demo mode
Set NEXUS_DEMO_MODE=true to enable deterministic simulated responses.

The demo exercises:
- FastAPI endpoints
- Enterprise, Personal, and Cybersecurity agent interfaces
- Multi-agent orchestration
- Conversation routing
- Decision reporting

Simulated responses are explicitly labeled. They are not generated by
a live language model and do not represent live security monitoring.

## Local full-AI mode
When NEXUS_DEMO_MODE is unset or false, the application retains its
local Ollama-compatible endpoint and Qwen model configuration.

## Secrets and persistence
Never commit .env files, API keys, or credentials.
The Render free service has an ephemeral filesystem. Local SQLite
data may be lost when the service restarts or redeploys.

## Deployment
Render reads the root render.yaml file.
The public demo does not require an OpenAI API key.


## Public demo privacy boundaries

- Conversation requests are stateless in demo mode; chat history is not read from or written to SQLite.
- Memory and user-profile CRUD endpoints return HTTP 403 in demo mode.
- Knowledge ingestion and retrieval are disabled in demo mode.
- The dashboard creates a distinct browser session identifier for local stateful development.
- Live/local-AI mode is intended for trusted local development and controlled, single-operator environments. Per-user authorization exists in opt-in form: per-user API keys (`NEXUS_API_KEYS`) confine a request to one user's memory, profile and knowledge, while the legacy `NEXUS_API_KEY` remains an operator credential with access to every user's data.
- This is tenant isolation, not complete authentication and authorization. OIDC/JWT, expiry and revocation for the environment keys (stored keys have them, opt-in), roles beyond scoped user and operator, per-user views of AEGIS-X, activity and system data (those routes are administrator-only, not per-user), and shared rate limiting are not implemented, so live mode should not be exposed as an untrusted multi-user service on this basis alone.

The public demo runs in deterministic demo mode. It does not use live Ollama reasoning, persistent conversation memory, or live RAG retrieval. Shared activity-history endpoints are not exposed, and API requests are throttled.
