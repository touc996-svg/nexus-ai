# NEXUS AI Public Demo

## Hosting
The public demo is configured for a Render free web service.

## Demo mode
Set NEXUS_DEMO_MODE=true to enable deterministic simulated responses.

The demo exercises:
- FastAPI endpoints
- Enterprise, Personal, and Cybersecurity agent interfaces
- Multi-agent orchestration
- Conversation routing
- Decision reporting

Simulated responses are explicitly labeled. They are not generated by
a live language model and do not represent live security monitoring.

## Local full-AI mode
When NEXUS_DEMO_MODE is unset or false, the application retains its
local Ollama-compatible endpoint and Qwen model configuration.

## Secrets and persistence
Never commit .env files, API keys, or credentials.
The Render free service has an ephemeral filesystem. Local SQLite
data may be lost when the service restarts or redeploys.

## Deployment
Render reads the root render.yaml file.
The public demo does not require an OpenAI API key.
